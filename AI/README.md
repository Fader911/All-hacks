# Flappy Bird Game

A simple 2D implementation of the classic Flappy Bird game using Python and Pygame.

## Requirements
- Python 3.x
- Pygame

## Installation
1. Install the required dependencies:
```bash
pip install -r requirements.txt
```

## How to Play
1. Run the game:
```bash
python flappy_bird.py
```

2. Controls:
- Press SPACE to make the bird flap
- Press SPACE to restart after game over

## Game Rules
- Avoid hitting the pipes
- Each pipe you pass through gives you 1 point
- The game ends when you hit a pipe or the ground

## Features
- Simple and clean graphics
- Score tracking
- Game over screen with restart option
- Smooth bird movement with gravity physics
